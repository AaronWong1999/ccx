## A heads-up before Codex asks you to trust a folder

When CCX is about to introduce a new folder to Codex, it shows the exact path and explains what folder trust allows. Choose Open Codex to continue to Codex's own confirmation. Cancelling pauses the first import so you can retry when ready. Existing projects continue through the usual transfer flow.

This release includes the 0.2.4 fixes for project registration, preserving the imported history, and reusing the same chat on retry.

---

## Codex 打开新目录前先提示

CCX 在把新目录交给 Codex 前会显示完整路径，并解释信任目录允许哪些操作。点「打开 Codex」后，由 Codex 显示原生确认。取消会暂停首次导入，之后可以重试。已有项目仍按原流程转移。

本版包含 0.2.4 的项目登记修复，保留导入历史，重试时复用同一条聊天。
