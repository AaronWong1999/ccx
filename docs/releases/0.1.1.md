## Smooth installation and updates · 安装与升级修正

Includes the Claude ⇄ Codex ⇄ Antigravity release from 0.1.0, plus:

- Reinstalling identical menu code reuses the existing app instead of compiling and signing it again. This avoids unnecessary app identity changes and related permission prompts.
- Builds compile and sign before replacing the installed app, with rollback if the final rename fails or the update is normally interrupted.
- Updates now report failures in installed-app plugins or the menu build, rather than announcing success. Retry with `ccx setup`; conversations and links stay intact.
- The installation script selects only stable `vX.Y.Z` tags, just like the built-in updater.
- Isolated install-script tests cover fresh installation, reinstallation, pre-release filtering, network failures and setup failures without modifying user configuration.

同版本重复安装不再强制重编译，减少不必要的授权重询问。编译失败保留旧菜单栏，安装步骤失败会明确报错；网络失败不会继续切换版本。现有对话与关联保留。仍使用复制脚本安装、本机编译，不需要 Developer ID 证书。

For the three-app workflow and macOS folder permissions, see [0.1.0](https://github.com/AaronWong1999/ccx/releases/tag/v0.1.0).
