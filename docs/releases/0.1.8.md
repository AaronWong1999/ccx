## Switching back to Antigravity brings the progress with it · 切回 Antigravity 时进展直接带过去

- **New progress shows up in Antigravity as soon as you switch.** Say you moved a task to Antigravity, kept working in Claude or Codex, and then switch back. Before, the new progress waited for your next message there: the conversation you opened showed none of it, and the agent didn't know it yet. Now ccx brings it in right away, as a "⇄ Progress from Claude" card, so you can just keep going. This needs Antigravity 2.34 or later.
- **The agent only acknowledges it.** Antigravity always answers a message like this, so ccx asks for a one-line reply and no work. That reply uses the model you picked in Antigravity. The card and the reply are never synced back to the other app.
- **Nothing is interrupted.** If Antigravity is in the middle of a task, or an older version can't take the card, ccx leaves the progress where it was. It comes along with your next message there, as before.
- **The first import into Antigravity finishes a little faster and more reliably.** ccx now uses Antigravity's own check for when a conversation has finished replying, instead of asking once a second.

If you are on the script, `ccx update` picks this release up on its own. The app download is below.

- **切回 Antigravity，新进展马上就在那里。** 比如任务已经转到 Antigravity，你又在 Claude 或 Codex 里继续做了一段，再切回来。以前新进展要等你在那边发下一条消息才带进去：打开的对话里看不到，那边的模型也还不知道。现在 ccx 会立刻带过去，显示为一张「⇄ 来自 Claude 的进展」卡片，直接接着说就行。需要 Antigravity 2.34 或更新版本。
- **那边只回一句确认。** Antigravity 收到这类消息一定会回复，所以 ccx 要求它只回一句话、不开始干活。这句回复用的是你在 Antigravity 里选的模型。卡片和这句回复都不会同步回另一边。
- **不会打断正在做的事。** Antigravity 正在跑任务，或者旧版本收不了卡片时，ccx 不动这些进展，还是等你下一条消息时再带过去，和以前一样。
- **首次导入 Antigravity 结束得更快、更稳。** ccx 现在用 Antigravity 自己提供的方式判断对话是否已经回复完，不再每秒查一次。

已经在用脚本的，`ccx update` 会自己更新到这一版；App 下载见本页附件。
