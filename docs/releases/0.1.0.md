## Claude ⇄ Codex ⇄ Antigravity

ccx now connects all three desktop apps. Move a task from any one to either of the others, or bring another app's conversation into the chat you are already in. Linked conversations receive new progress with your next message. Existing Claude–Codex links keep working.

- The ⇄ menu groups conversations by project and app. Pick a conversation, then **Continue in Claude / Codex / Antigravity**. Each destination shows whether this is a first import, already synchronized, or has pending progress.
- Tasks in all three apps are linked automatically, with a separate progress cursor for each destination. Unlink one pair without removing conversations or the other links.
- New Antigravity skills, MCP tools and a sync hook; the Codex directory package and magpie plugin also support Antigravity.
- Preparing progress from several apps is retry-safe: a source that fails to render doesn't consume the others' progress.

### Antigravity behavior

Antigravity has no native history-import or open-specific-conversation link. ccx starts a conversation with condensed context, waits for a short acknowledgement, then tells you its project and `⇄ …` title in the sidebar. That acknowledgement uses your Antigravity model. Later progress arrives through its PreInvocation hook. Its local RPC is private and may need adapting after an Antigravity update; validated with desktop version 2.32.1.

### 本次更新

支持 Claude、Codex、Antigravity 三方任意互转。菜单路径为 **⇄ → 项目 → 会话 → 去哪个 app 接着干**；每个去向都标明“首次导入并关联／已同步／有新进展”。已有双向关联继续有效，第三方加入后自动补齐关联，也可单独取消其中一条。

Antigravity 首次接收任务时会新建对话、带入压缩后的上下文并回复一句确认。它没有打开指定对话的链接，因此 ccx 会打开 App 并提示项目和对话标题；之后在关联对话发消息就会带入新进展。

Validation: Python 3.9 and 3.14 unit tests, magpie tests, Swift menu build and menu/click checks, plus local imports and bidirectional sync against the installed desktop apps.
