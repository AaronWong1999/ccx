## Fixed opening imported conversations in Codex

CCX now checks Codex's project service as well as the legacy desktop index. On the first transfer into a folder, the menu reminds you to confirm folder trust if Codex asks and gives you time to respond. If the project is still pending, a first import pauses. A previously linked chat can still open, and retrying checks its project without creating a duplicate.

---

## 修复导入后无法打开 Codex 聊天

CCX 现在同时检查 Codex 的项目服务和旧版桌面索引。首次转入某个目录时，菜单会提醒你留意 Codex 的目录信任弹窗，并留出确认时间。项目仍待确认时，首次导入会暂停。已经关联的聊天仍可打开，再次转移会重新检查项目归属并复用原聊天。
