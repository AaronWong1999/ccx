## Claude's quota in the menu, and a quota row you can't misread · 菜单里有 Claude 额度了，数字也不会再看错

- **Claude's quota, from Claude Code itself.** Claude Code fetches your account's 5-hour and weekly usage from Anthropic while you use it (the same numbers its `/usage` shows) and keeps the last reading on disk. ccx now reads it. In 0.1.4 Claude only showed up once it hit a limit or a separate usage tool was installed, so the menu often listed just Codex and Antigravity.
- **The quota row says what is left.** It now reads `5-hour quota left: Claude 97% · Codex 100% · Antigravity 100%`. 0.1.4 showed a bare `0%`, which could mean either used or left. A used-up app shows `used up (back 17:00)`, and an installed app with no reading right now shows `unknown` instead of disappearing.
- `ccx usage` prints both numbers, for example `3% used (97% left)`.

If you are on the script, `ccx update` picks this release up on its own. The app download is below.

- **直接读取 Claude Code 自己的额度。** Claude Code 在使用时会向 Anthropic 拉取你账号的 5 小时和每周额度（和它的 `/usage` 一致），并把最后一次读数存在本地。ccx 现在读取它。0.1.4 里 Claude 只有撞限或另装了额度工具时才显示，所以菜单常常只有 Codex 和 Antigravity。
- **额度一行写明是剩余。** 现在显示为 `5 小时额度剩余：Claude 97% · Codex 100% · Antigravity 100%`。0.1.4 只写一个 `0%`，看不出是已用还是剩余。用完的显示 `已用完（17:00 恢复）`；装了但暂时读不到的显示 `未知`，不再直接消失。
- `ccx usage` 两个数都列出，例如 `3% used (97% left)`。

已经在用脚本的，`ccx update` 会自己更新到这一版；App 下载见本页附件。
