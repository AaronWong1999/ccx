## ZCode imports go into the matching project

ccx matches the source folder to an existing ZCode project. For a new folder, it opens ZCode's own confirmation and waits for the project before importing the conversation. Confirming the folder once is enough for subsequent imports. If the project isn't confirmed, the import pauses. The model fallback from 0.2.2 is included.

---

## 导入 ZCode 时归入对应项目

ccx 按工作目录匹配 ZCode 项目。首次转入新目录时，ccx 打开 ZCode 的原生确认，等项目建好后再导入会话。以后转入同一目录会直接使用该项目。未确认目录时，导入会暂停。这一版也包含 0.2.2 的模型回退修复。
