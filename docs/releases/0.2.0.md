## Claude ⇄ Codex ⇄ Antigravity ⇄ ZCode

ccx now connects four desktop apps. [ZCode](https://zcode.z.ai), Z.ai's coding app with the GLM models, joins Claude Code, Codex and Antigravity: move a task from any one to any other, or bring another app's conversation into the chat you are in. Existing links keep working, and a task linked in all four stays one task.

- **A native import into ZCode.** A task sent there becomes a ZCode conversation with the whole history, through the same import ZCode uses for "Import from Claude Code", on the model you last picked in ZCode. Nothing is sent to the model until you write there.
- **No clicks to find it.** ZCode only lists a conversation made outside it after a restart, and has no refresh. When ZCode is idle, ccx quits it and opens it again on the project, with the new conversation at the top. When a ZCode task is running, ccx asks first, and can restart ZCode once that task is done. When ZCode is closed, it just opens.
- **Back and forth.** Progress made in ZCode comes along with your next message in Claude, Codex or Antigravity, and theirs reaches ZCode through its plugin hook with your next message there. ZCode conversations can be handed to the others the same way, from ⇄, with `/to-zcode` · `/from-zcode` in Claude, `$to-zcode` · `$from-zcode` in Codex, or by asking in ZCode or Antigravity.
- **Nothing to turn on.** Once you have opened ZCode, `ccx update` installs the ccx plugin into it with ZCode's own `zcode plugins` command. The first time can take a few minutes, because ZCode refreshes its plugin sources.
- The ⇄ menu, `ccx ls`, the MCP tools and the magpie plugin list ZCode conversations too. ZCode's quota is not shown in the menu.

If you are on the script, `ccx update` picks this release up on its own. The app download is below.

### 本次更新

ccx 现在连接四个桌面 app。Z.ai 的编程 app [ZCode](https://zcode.z.ai)（GLM 模型）加入 Claude Code、Codex 和 Antigravity：任意一家的任务都能转给任意另一家，也能把别家的对话带进当前对话。已有的关联继续有效，四家都关联的任务仍是同一个任务。

- **原生导入 ZCode。** 传过去的任务会成为一个带完整历史的 ZCode 对话，走的是 ZCode 自己“从 Claude Code 导入”用的同一个接口，模型用你在 ZCode 里最近选的那个。你在那边发消息之前，不会调用模型。
- **不用点任何东西就能看到。** ZCode 只有重启后才会列出外部创建的对话，也没有刷新功能。ZCode 空闲时，ccx 会把它退出再在对应项目上打开，新对话就在最上面；ZCode 有任务在跑时会先问你，可以等那个任务完成后再重启；ZCode 本来没开就直接打开。
- **来回同步。** ZCode 里的进展会在你下次给 Claude、Codex 或 Antigravity 发消息时带过去；它们的进展通过 ZCode 的插件 hook，在你下次在 ZCode 发消息时带进去。ZCode 的对话也能同样转出去：用 ⇄ 菜单，Claude 里的 `/to-zcode` · `/from-zcode`，Codex 里的 `$to-zcode` · `$from-zcode`，或者在 ZCode、Antigravity 里直接说。
- **不用开任何开关。** 打开过 ZCode 后，`ccx update` 会用 ZCode 自己的 `zcode plugins` 命令把 ccx 插件装进去。第一次可能要几分钟，因为 ZCode 会刷新它的插件源。
- ⇄ 菜单、`ccx ls`、MCP 工具和 magpie 插件都会列出 ZCode 的对话。菜单里暂不显示 ZCode 的额度。

已经在用脚本的，`ccx update` 会自己更新到这一版；App 下载见本页附件。

Validation: Python unit tests (138, including a ZCode store in its real shape), magpie tests, Swift menu type check, plus local imports both ways, the ZCode hook bringing Claude's progress in, and the restart against the installed ZCode 4.0.0.
