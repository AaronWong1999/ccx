## The menu bar app as a download, for both kinds of Mac · 菜单栏 App 可直接下载（两种 Mac 都能用）

Every release so far shipped no file at all: installing ccx meant running the one-line script, which compiles the menu bar app on your own Mac. This release adds the app itself as a download, next to the script.

- **`ccx-0.1.3-macos.zip`** on this release page: the menu bar app, built from source on a clean runner. Unzip it and drag `ccx.app` to Applications.
- **It runs on both Apple silicon and Intel Macs.** The 0.1.2 download was built for one architecture only; this one is a single binary with both, so the same file works on either.
- The app carries no Developer ID signature, so macOS asks you to confirm it the first time you open it. That is the same trade the install script makes; the script remains the better path if you already have the Command Line Tools, because it also installs the plugin into the three apps and sets up the update path.
- Nothing about how ccx works changed. The app still reads your conversations locally and still moves a task between Claude Code, Codex and Antigravity with its context.

If you are on the script, `ccx update` picks this release up on its own.
