## Fixed conversation imports into ZCode

If ZCode's import service no longer recognizes the model used in your last ZCode conversation, ccx retries the import with ZCode's default model selection. The conversation history is saved without making a model request. If the previous model is still available, ccx keeps using it.

---

## 修复导入对话到 ZCode 失败

如果 ZCode 的导入服务找不到上次使用的模型，ccx 会改用 ZCode 的默认模型选择重试。导入会保存对话历史，期间不会发起模型请求。上次的模型仍可用时，ccx 会继续使用它。
